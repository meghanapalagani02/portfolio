HOW TO PREVIEW LOCALLY (QUICK & EASY)
--------------------------------------------------------------------------------
Option 1: Using Python (Recommended & already installed)
1. Open PowerShell or Terminal in this folder:
   c:\Users\Megana\Documents\Portfolio\Meghana_Portfolio
2. Run:
   python -m http.server 8000
3. Open your browser and navigate to:
   http://localhost:8000

Option 2: Using VS Code "Live Server"
1. Open the folder in Visual Studio Code.
2. If you have the "Live Server" extension installed, right-click index.html
   and select "Open with Live Server".
3. The site will launch automatically in your default browser.

Option 3: Direct File Opening
- Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge,
  or any modern web browser.


HOW TO DEPLOY FOR FREE
--------------------------------------------------------------------------------
Option A: Deploy to GitHub Pages (Recommended, 100% Free)
1. Initialize a Git repository if not already done:
   git init
   git add .
   git commit -m "feat: complete editorial portfolio for Meghana Palagani"
2. Create a new repository on your GitHub account (https://github.com/meghanapalagani02)
   named `meghana-portfolio` or `meghanapalagani02.github.io`.
3. Link and push your code:
   git remote add origin https://github.com/meghanapalagani02/meghana-portfolio.git
   git branch -M main
   git push -u origin main
4. On GitHub, go to your repository Settings > Pages.
5. Under "Branch", select `main` and folder `/ (root)`, then click Save.
6. Your portfolio will be live at:
   https://meghanapalagani02.github.io/meghana-portfolio/

Option B: Deploy to Netlify (Drag & Drop, Instant & Free)
1. Go to https://www.netlify.com and log in or sign up.
2. Go to the "Sites" tab and drag the entire `Meghana_Portfolio` folder into the dropzone.
3. Netlify will deploy it in seconds with a free `.netlify.app` domain and free SSL certificate.

Option C: Deploy to Vercel (Free)
1. Go to https://vercel.com and import your GitHub repository.
2. Keep root directory as `./` and click Deploy.
